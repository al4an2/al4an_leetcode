# LeetCode Practice

A lightweight journal of LeetCode/LeetCode-style problems.

## Layout

Every problem lives under `tasks/<topic>/`, grouped by the approach the solution
actually uses — not by the tags LeetCode lists.

- Plain solution: `tasks/<topic>/<id>_<Task_Title>.py`
- Solution with a write-up: `tasks/<topic>/<id>_<Task_Title>/` containing the
  `.py` file and a `README.md` with the idea, the algorithm and the complexity.

Filenames mirror the LeetCode title, with spaces replaced by underscores, so the
problem is searchable by both its number and its name.
